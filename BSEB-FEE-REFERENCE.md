## 4. Intermediate Registration / Examination

Official current registration portal:
- `https://intermediate.biharboardonline.com/`

The public portal currently identifies the academic registration cycle and provides registration-payment/form workflows, but a complete current fee table is not reliably exposed in the public page text available for verification.

For this reason, the school website must **not hard-code an old Intermediate registration amount as current** without the applicable BSEB notice.

For the current 2027 examination cycle, published reporting citing BSEB instructions lists a total of **₹1,430** for Regular / Private / Ex-Student candidates appearing in the main Intermediate examination (₹1,400 committee fee + ₹30 institution examination-related charge). Other categories such as improvement/additional/vocational candidates have different totals.

Status: **Use as review reference only; confirm from the current official Intermediate notification before payment/public finalization.**

## 5. Public Display Rule

Every fee shown on the school website should include:

- fee purpose (Admission / Registration / Examination);
- class/level (Secondary / Intermediate);
- applicable session/exam year;
- category (Regular / Independent / Reserved / special category);
- source URL/PDF;
- verification date;
- status (`Verified`, `Re-verify before payment`, or `Archived`).

Do not combine OFSS application fee with institution admission charges. Do not combine BSEB registration fee with examination fee.

---

## 6. Change Governance

When BSEB publishes a new fee notice:

`Official notice/PDF → AI/manual extraction → compare existing fee → Review Queue → human verification → update staging → user approval → production`

No AI-generated or third-party fee amount should silently replace a verified official amount.
