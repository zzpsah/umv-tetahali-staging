# Photo & Signature Studio

## Purpose
Prepare student photographs and signatures for school/BSEB-style workflows: detect relevant regions, crop, clean, enhance, and produce portal-ready image outputs.

## Basic flow
```text
Student Form / Image / PDF
        │
        ▼
Document Vision / OCR
        │
        ├── Photo region
        └── Signature region
        │
        ▼
Crop + Clean + Enhance
        │
        ▼
Preview / Human Review
        │
        ▼
Download / Drive workflow
```

## Use
Open the live tool from the IT Services page, upload the permitted source document, review detected photo/signature regions, correct if needed, then export the final images.

## Important
Always verify the final photo/signature before registration or official submission.
