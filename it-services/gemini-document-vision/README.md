# Gemini Document Vision

## Purpose
AI-assisted visual analysis of documents to identify useful regions such as student photographs and handwritten signatures.

## Flow
```text
Document image → Gemini Vision → Region identification → Human review → Crop/process → Output
```

## Use
Used as an assisted component inside document/photo processing workflows. Review the detected regions before accepting them.

## Important
AI detection can be wrong. Never treat an AI result as an official record without operator verification.
