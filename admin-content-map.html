Recommended implementation

  1. Admin login के बाद यही Content Management hub खुले।
  2. हर category का अलग form/page हो; सभी records में unique ID और output target हो।
  3. Save → Draft → Review → Approve → Publish workflow रखें।
  4. Public output को एक ही source record से generate/render करें, ताकि एक जानकारी दो जगह अलग-अलग न हो।
  5. Phase 2 में approved records को Supabase में रखने और PDFs को private/public Google Drive folders से जोड़ने का backend बनाया जाए।
