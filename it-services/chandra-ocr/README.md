# Chandra OCR

## Purpose
Extract text and document layout from scanned forms, PDFs, and photographs so the information can be reviewed and used by later school workflows.

## Flow
```text
Scan / PDF / Photo → Chandra OCR → Structured text/layout → Human verification → Automation
```

## Use
This capability is currently integrated into the document-processing workflow rather than exposed as a separate public app.

## Important
OCR is an extraction aid, not the final source of truth. Compare important fields with the original document before using them for registration or official records.
