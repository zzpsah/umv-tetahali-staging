File Naming & Source Rule

  • Document का नाम उसके वास्तविक उपयोग के अनुसार होगा, जैसे BSEB Student Document, न कि केवल “BSEB”.
  • Portal और document अलग रहेंगे: BSEB Portals portal links के लिए, आधिकारिक दस्तावेज़ केन्द्र actual files के लिए।
  • हर file record में Date + Type + Document/File Name + Description + Official Document/PDF रहेगा।
  • Original official PDF/image source of truth रहेगा।
  • Verified official file/link न मिलने पर Official Document field खाली रहेगा—कोई अनुमानित link नहीं जोड़ा जाएगा।
